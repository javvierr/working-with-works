- Normalize only the five recognized control declarations: absent, empty and whitespace-only values become absent. Preserve nonblank values rather than silently trimming them. Every nonempty forbidden PG or unknown database URL override still refuses, including whitespace.
- Reject conflicting nonblank Rails/Rack environments before dependency checks or child dispatch. CI protects every declared development URL and also inherited DATABASE_URL unless there is a consistent explicit test context. A blank or preferred declaration cannot mask another applicable target. Minimal CI with only the test URL remains valid.
- Compare decoded database names, with case preserved, across each applicable development/test pair regardless of endpoint or role spelling. This conservative contract intentionally refuses equally named databases on separate servers; it does not claim to resolve aliases or discover undeclared databases.

Existing query override and explicit endpoint/port/role/non-maintenance-name validation remains. Scoped IPv6 needing an encoded authority zone is outside this narrow interface.

- Keep schema readiness helpers, migrations, bin/setup, bin/ci, CI step wiring, dependencies and evaluated application code unchanged. The only executable correction is the target helper; focused tests retain existing meaningful schema/refusal/failure coverage and add the supplied matrix.
