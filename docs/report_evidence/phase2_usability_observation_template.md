## Recording rules

For each planned task, select exactly one attempt disposition:

- `attempted`
- `not_attempted_after_withdrawal`

The five completion statuses and all time, assistance, wrong-turn, ease and other measurement fields are completed only when disposition is `attempted`. When disposition is `not_attempted_after_withdrawal`, leave those fields blank. Never use `not_completed` or `technical_interruption` for a task that did not start.

Use exactly one completion status per attempt:

- `completed_independently`
- `completed_with_neutral_prompt`
- `completed_with_task_specific_help`
- `not_completed`
- `technical_interruption`

If withdrawal occurs after a task instruction was read, that task remains `attempted`. When retention is permitted, record only what was actually observed; if the task stopped before completion, select `not_completed` and note that withdrawal ended it. Do not treat withdrawal as an interface failure or include it in issue severity.

If withdrawal and a technical problem occur together, select `technical_interruption` only when the technical problem independently prevented or invalidated the attempted outcome. Otherwise select `not_completed` and record withdrawal as the reason the attempted task ended.

The only neutral prompt is `“Please continue in the way that seems most natural”`. Repeating the task wording verbatim is not assistance. Any other directional assistance is task-specific help.

Timing starts after the task is read and stops on completion or at 180 active seconds. Pause timing for technical interruptions and record paused seconds separately.

A wrong turn is a deliberate action that moves away from the task goal and requires reversal. Reading, pausing or scrolling alone is not a wrong turn.
